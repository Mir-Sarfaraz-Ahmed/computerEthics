# Computer Ethics — Keynote Interactive Presentation (React SPA)

An Apple Keynote-inspired interactive presentation exploring modern dilemmas in computer ethics, software copyright, and digital rights, rewritten as a modern React application with TypeScript and Vite.

---

## 🌟 Highlights & Features

- **Authentic Apple "hello" Intro**: Custom SVG calligraphy stroke animation inspired by classic macOS setup sequences.
- **Synthesized Web Audio Engine**: Integrated Web Audio oscillators generating Apple-style startup chords, ambient feedback, paper plane flight whoosh, and interactive warning cues without external audio files.
- **Stage 1 — What is Computer Ethics, Actually?**:
  - Ultra-cinematic duality scene contrasting artificial intelligence vs. human philosophy with real-time mouse parallax.
  - Interactive two-step reveal with kinetic typography and particle canvas.
- **Stage 2 — The Dilemma (GTA V Case Study)**:
  - 3-stage visual narrative: Blank screen → Official Store screen → The Crossroads.
  - Parallax and dynamic screen glow effects.
- **Stage 3 — Two Paths. One Choice**:
  - Side-by-side comparison cards: Path A (The Ethical Contract) vs. Path B (The Free Illusion).
  - Deep-dive discussion cards for economic justice, digital integrity, and hidden malware payloads.
- **Cinematic Paper Plane Transition**:
  - Animated paper plane soaring through clouds and sky, bridging case studies to core definitions.
- **Stage 4 — Computer Ethics Definition**:
  - James H. Moor (1985) seminal definition breakdown with green particle ambient canvas.
- **Presenter Controls**:
  - Full bidirectional keyboard navigation (`Space`, `Enter`, `ArrowRight`, `ArrowLeft`, `Escape`).
  - Dark Mode and Light Mode theme toggle.
  - Sound synthesis mute/unmute toggle.
  - macOS window actions with toast feedback and fullscreen toggle.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Built With

- **React 19 & TypeScript**: Component-driven architecture and typed state machine.
- **Vite**: Ultra-fast dev server and optimized production bundler.
- **Web Audio API**: Real-time sound synthesis for rich interactive feedback.
- **Canvas 2D**: Responsive ambient orbs and atmospheric particle systems.
- **Custom Keynote CSS**: Glassmorphism, compositor animations, and typography (`Plus Jakarta Sans`, `Cinzel`, `JetBrains Mono`).
