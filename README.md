# Computer Ethics — Keynote Interactive Presentation

An Apple Keynote-inspired interactive presentation exploring modern dilemmas in computer ethics, software copyright, and digital rights.

---

## 🌟 Highlights & Features

- **Authentic Apple "hello" Intro**: Custom SVG calligraphy stroke animation inspired by classic macOS setup sequences.
- **Synthesized Web Audio Engine**: Integrated Web Audio oscillators generating Apple-style startup chords, ambient feedback, and interactive warning cues without external audio dependencies.
- **Stage 1 — What is Computer Ethics, Actually?**:
  - Ultra-cinematic duality scene contrasting artificial intelligence vs. human philosophy.
  - Interactive two-step reveal with zero-latency kinetic typography.
- **Stage 2 — The Piracy Dilemma ("You've probably seen this before.")**:
  - Split-screen comparison: Official Store (₹1,999) vs. Pirate / Cracked Portal.
  - Interactive hotspot inspection cards with legal verification vs. security risk telemetry.
  - Philosophical breakdown deck exploring Labor vs. Scarcity, the "Victimless" myth, and Global Purchasing Power Disparity.
  - Live interactive audience ethics poll with real-time percentage recalculations.
- **Presenter Keyboard & Gesture Controls**:
  - <kbd>Space</kbd> or <kbd>→</kbd> : Advance to next stage / slide reveal.
  - <kbd>←</kbd> : Step back to previous stage.
  - <kbd>Esc</kbd> : Return to presentation cover.

---

## 🚀 Quick Start

Run locally with any static web server:

```bash
# Using Node / npx
npx serve . -l 3000

# Using Python 3
python -m http.server 3000
```

Then open [http://localhost:3000](http://localhost:3000) in any modern browser.

- **HTML5 & Vanilla CSS3**: Fluid layouts, backdrop-filters, custom keyframes, and 60 FPS compositor-friendly animations.
